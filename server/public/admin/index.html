Danh sách user

Một gói: mỗi user một hạn ký tự (max_chars). Lần đầu Lưu hạn (số > 0) → tự đặt hết hạn +1 tháng kể từ lúc đó; sau mốc hết hạn user không đăng nhập / không dùng được. Bấm Gia hạn +N tháng để cộng thời gian từ ngày hết hạn hiện tại (hoặc từ hôm nay nếu đã quá hạn) và reset đếm ký tự về 0. Để trống ngày + Lưu hết hạn = bỏ khóa theo ngày (chỉ còn logic tháng dương lịch nếu không có ngày hết hạn). Migration 007 + 008.

Proxy pool (Supabase)

Nguồn chính Webshare: bấm Đồng bộ Webshare ngay để gọi API lấy list proxy mới nhất (link cấu hình ở WEBSHARE_LIST_URLS trên Vercel) và nạp vào pool (source=webshare). Dòng webshare không gọi API đổi IP, không cooldown 60s → lease/xoay IP nhanh nhất, luôn được ưu tiên trước. Có cron tự động 1 lần/ngày (03:00 UTC — gói Hobby Vercel giới hạn tối đa 1 lần/ngày, xem vercel.json). Cần đồng bộ gấp/thường xuyên hơn: bấm nút này bất cứ lúc nào, hoặc trỏ cron ngoài (cron-job.org…) gọi POST /api/cron/sync-proxies với header X-Cron-Secret (nâng cấp Pro để cron nội bộ chạy nhiều lần/ngày). Chạy migration 011_webshare_backup_pool.sql trên Supabase trước khi dùng nút này.

Nguồn backup proxyxoay.shop: mỗi dòng dán 1 key mua từ proxyxoay.shop (tuỳ chọn thêm |whitelist_ip nếu vendor yêu cầu, mặc định để trống). Bấm Thêm key proxyxoay → server gọi thử API xoay ngay để lấy gateway host:port, lưu source=proxyxoay. Nguồn này xoay IP qua API (có cooldown 60s), dùng khi pool Webshare cạn/không đủ. Key hết hạn/không tồn tại (server tự phát hiện lúc lease hoặc bấm Recheck) sẽ tự bị xoá khỏi DB. Chạy migration 013 + 014 + 015 trên Supabase trước khi dùng (migration 015 xoá hẳn nguồn 1ip.vn cũ).

Dòng trạng thái dưới nút: tổng số bản ghi ≠ chỉ proxy đang được app cấp phát. Recheck chỉ áp dụng cho nguồn proxyxoay (Webshare không có API kiểm tra riêng). Gia hạn gói user và gói proxy là hai việc tách nhau.
